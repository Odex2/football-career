# Changelog

The game was built in milestones (M1, M2...). Only the code of v0.8 and later was kept, so the git history starts there; the earlier versions are described below.

## v1.0 · 2026-11-19 · First public release

- Renamed to **Football Career**.
- Real footballers' names replaced by common, invented names for every nationality.
- English README, MIT license, contributing guide, automated checks on GitHub Actions, playable on GitHub Pages.

## v0.9 · 2026-11-02 · Manager career, part 2 (M9, steps 1–6)

- **Formation** (S1): a clearer formation tab, tap to select and swap players, undo, and an optional assistant that rotates the squad.
- **Changing club** (S2): the coaches' job market, with clubs' interest in you, open benches, offers and interviews.
- **Club identity** (S3): every club asks for one or two traits (youth, solid defence, show...), checked at the interview and through the season.
- **The board** (S4): a yearly pact between budget and targets, the president's confidence and requests during the season.
- **Player positions** (S5): 11 positions on top of the 6 roles, with familiarity and natural position; surnames with particles (de Jong, El Amrani) kept whole.
- **Tactics** (S6): three levers (pressing, build-up, defensive line), tactical familiarity and counter-moves.

## v0.8 · 2026-10-23 · Manager career, part 1 (M8)

- South American nationalities and a random first club.
- A FIFA-style squad for the manager: roles, morale, form, injuries, captain.
- Pre-match screen and live matches with half-time decisions.
- Transfer market with search filters and scouts, youth academy, the board and its goals.
- Formation on a pitch, a new main screen and Profile tab, the season's match calendar.
- TypeScript type checking (JSDoc, `tsc` only as a checker) and fixed-seed test careers.

## v0.1–v0.7 · 2026-10-20/22 · Player career

- **M1**: the world, player creation, the season in five blocks, attributes with age curves, saving.
- **M2**: transfers and agent, playing time, morale, event cards, rivalries and club legend.
- **M3**: national team and international tournaments, awards, achievements, end-of-career animation, Hall of Fame.
- **M4**: balance and speed.
- **M5–M7**: more depth for the player career, a first manager mode and the trophy cabinets.
